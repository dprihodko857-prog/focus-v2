Эта политика описывает, какие данные используются сервисом Focus для работы планировщика, синхронизации, уведомлений и будущих платных функций. Перед запуском приема платежей и публичной рекламой сервиса текст рекомендуется дополнительно проверить с юристом.

1. Оператор

Оператор данных: индивидуальный предприниматель Приходько Дмитрий Геннадьевич. Контакты и реквизиты опубликованы на странице requisites.html. Для обращений используется e-mail dmprihodko@mail.ru.

2. Какие данные может обрабатывать Focus

  • Данные планирования: расписания, напоминания, дела, заметки, дни рождения и записи дневника, если пользователь сохраняет их в приложении.
  • Данные аккаунта синхронизации: код аккаунта, название аккаунта, название устройства и технические данные подключенных устройств.
  • Данные уведомлений: push-подписка устройства, статусы доставки и журнал технической диагностики уведомлений.
  • Данные авторизации, если пользователь входит через подключенный сервис авторизации: идентификатор аккаунта, имя или e-mail, если они переданы провайдером.
  • Платежные статусы и идентификаторы операции после подключения платежного провайдера. Полные данные банковской карты Focus не хранит.
  • Текст, полученный из голосового ввода, после запуска функции транскрибации. Аудио будет использоваться только для распознавания речи, если такая обработка будет подключена.

3. Цели обработки

  • Работа календаря, расписаний, напоминаний, заметок и личного дневника.
  • Синхронизация данных между устройствами пользователя.
  • Доставка локальных и push-уведомлений.
  • Предоставление доступа к платным функциям после оплаты.
  • Поддержка пользователя и диагностика технических ошибок.

4. Где хранятся данные

Часть данных хранится локально в браузере или PWA на устройстве пользователя, включая IndexedDB. При включенной синхронизации данные передаются на backend Focus, чтобы пользователь мог работать с несколькими устройствами одного аккаунта.

PIN личного дневника используется для ограничения доступа на устройстве. При включенной синхронизации содержимое дневника может передаваться на сервер вместе с другими данными аккаунта.
