# Каталог праздничных календарей Focus

Дата: 2026-08-04

## Цель

Focus получает системные праздничные события без отдельного фронтенда, базы или авторизации. Каталог встроен в существующее PWA, синхронизируется через `server/sync-server.mjs` и отображается в основном календаре как readonly-события.

## Архитектура

- `public/js/holiday-catalog.js` содержит опубликованный RU-2026 каталог, справочники, нормализацию, валидацию, dry-run импорт и выборку событий по дате.
- `server/sync-server.mjs` отдает опубликованный каталог через `/api/holiday-calendars/*` и хранит только безопасные пользовательские настройки праздников.
- `public/js/sync.js` добавляет client API и bundled fallback для offline/PWA режима.
- `public/js/storage.js` кэширует каталог, серверные настройки и локальные религиозные настройки в IndexedDB с fallback на localStorage.
- `public/js/app.js` добавляет настройки, initial setup и readonly-события в месяц, карточку дня, неделю и сводку.

## Privacy

Серверные holiday preferences не содержат религиозные поля. На сервер уходят только:

- страна календаря;
- включение государственных праздников;
- включение переносов выходных;
- режим профессиональных праздников;
- выбранные профессиональные категории;
- скрытые calendar id;
- флаг завершения настройки.

Выбор религиозных традиций хранится только локально в ключе `focusHolidayReligiousPreferences`. Даже если клиент передаст `selectedTraditions` или `religiousTraditions` в `/api/holiday-preferences`, серверная нормализация их отбросит.

## Источники RU-2026

Каталог собран вручную из опубликованных источников и не вызывает внешние API на клиенте:

- ТК РФ, статья 112, для государственных нерабочих праздничных дней.
- Постановление Правительства РФ от 24.09.2025 N 1466 для переносов выходных 2026 года.
- Патриархия, Vatican.va и ДУМ РФ для религиозных календарей.
- Проверяемый seed профессиональных дат RU-2026 с категориями Focus.

Для RU-2026 в каталоге отдельно заведены дополнительные нерабочие дни: 9 января и 31 декабря по постановлению N 1466, а также 9 марта и 11 мая по правилу статьи 112 ТК РФ о переносе выходного при совпадении с нерабочим праздничным днем.

## Admin Workflow

Проверить bundled опубликованный каталог:

```bash
node scripts/holiday-catalog-admin.mjs validate
```

Проверить внешний JSON перед staged import:

```bash
node scripts/holiday-catalog-admin.mjs dry-run path/to/catalog.json --target=approved
```

Команда `dry-run` не публикует каталог напрямую в production. Production-использование требует `status: "published"` и успешную `validateHolidayCatalog(..., { targetStatus: "published" })`.
